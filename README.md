# ⚙️ .github - Taverna Web

Este é um repositório especial que contém os recursos globais e partilhados para toda a organização **Taverna Web**. 

O objetivo deste repositório é centralizar configurações para manter a consistência em toda a nossa arquitetura de multirepos (frontend e backend).

## 📁 O que está neste repositório?

* **Perfil da Organização:** O ficheiro que serve como montra principal na página pública da nossa organização, apresentando o ecossistema completo do projeto.
* **Ficheiros de Comunidade (Futuro):** Espaço reservado para adicionar configurações globais, como templates de *Issues*, templates de *Pull Requests* ou políticas de segurança, que se aplicarão automaticamente a todos os nossos repositórios de código.

---
Para explorar o código da plataforma, aceda aos repositórios `taverna-web-frontend` e `taverna-web-backend` na página da organização.
